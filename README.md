# Social Media Popularity Prediction Using AIML

## About the Project
An AI/ML-based project for analyzing and predicting social media popularity using datasets and machine learning techniques

## Objectives
- Analyze social media popularity patterns.
- Process and explore datasets.
- Identify features that influence content popularity.
- Predict popularity using machine learning.

## Technologies Used
- Python
- Machine Learning
- HTML
- CSS
- CSV datasets

## Project Structure
- `Database` – Database-related files.
- `Remote_User` – Remote user module.
- `Service_Provider` – Service provider module.
- `Template` – Web application templates.
- `Datasets.csv` – Dataset.
- `Datasets1.csv` – Additional dataset.
- `Results.csv` – Results data.

The project includes documentation covering system architecture, algorithms, diagrams, testing, modules, and conclusion.
